A program that writes the one sentence a house cat would say in its own defence after knocking a glass off the table — no apology, no confession, just the most convincing case a cat can make for itself. Entry for make.fun's "Five Seconds to Explain the Glass" bounty.

## Run it

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
